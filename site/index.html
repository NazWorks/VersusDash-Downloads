Install on Mac

  1. Download and open the ZIP.
  2. Move VersusDash into Applications.
  3. Open VersusDash normally from Applications.
  4. Choose Create Room and share the room code, or choose Join Room and enter a code from a friend.

Install on Windows

  1. Download and extract the Windows ZIP.
  2. Run VersusDash.exe.
  3. During the unsigned alpha, Windows may require More info → Run anyway. Confirm this page is the source before proceeding.
  4. Create or join a room with the same short codes used by Mac players.
